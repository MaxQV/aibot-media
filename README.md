# aibot-media

Публичные картинки к постам Aibot.pro. Metricool забирает медиа только по публичной ссылке,
поэтому карусели лежат здесь. Исходники и вёрстка — в приватном репозитории `Aibot-post-creation`
(`drafts/<пост>.cards.py` → `drafts/cards/<пост>/`).

Структура: `posts/<пост>/ru-1..7.jpg` (Instagram, Threads, Facebook), `posts/<пост>/en-1..7.jpg`
(LinkedIn, X). Файлы не переименовывать и не удалять: на них ссылаются запланированные посты.
